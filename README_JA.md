# BeatAdventure

**宇宙大戦の次の舞台は、古代遺跡だ！ ビートが、俺の魂を奮い立たせる。**

M5Stack Cardputer ADV(240 x 135)用の、音楽同期の冒険ゲームです。
[KeySpeaker](https://github.com/kariagepompadour/Cardputer-ADV-KeySpeaker) の姉妹品で、KeySpeaker のファームウェア(USB スピーカー、
USB と BLE のキーボード、エアマウス、ジョグダイヤル、内蔵マイク、Pico 2 の AUX ユニット、microSD の MP3)のゲーム画面を、
BeatAdventure のゲームに差し替えたものです。探検家は、音の大きさ、スペクトラム、拍に合わせて、走り、登り、泳ぎ、落ちながら旅をします。
探検家は自分で動くので、あなたは眺めるだけです。

**まずはブラウザで遊べます: https://kariagepompadour.github.io/BeatAdventure-WEB-DEMO/**(この実機版は、この WEB 版を元に移植しました。)

[English](README.md)

## 旅の流れ

WEB 版と同じ順で、ぐるっとつながる長い旅です。

1. **客船**: 左のはしごを登り(拍ごとに1段)、艦橋の屋根から海を眺め、屋根を渡り、右のはしごを降りて、タラップを下ります。
2. **浜辺**: 去っていく船、波、ヤシの木からココナッツを投げるサル、跳び越えるウミガメと流木、ときどき追ってくる仮面の狩人、
   曲が静かになると隠れる茂み。
3. **森**(丘、トラ、クマ、リンゴ)と **崖**: 落石とコンドルのなか、地すべりの壁を登ります。
4. **ツルの谷** と **ボートと滝**: 3本のツルで谷を渡り、ボートで滝を落ちます。
5. **川**(ワニ、ピラニア、水ヘビ)と **平らな森**(池、広い池を渡るツル、台座の上の黄金の仮面、隠し穴)。
6. **レンガのトンネル**(矢のわな、転がる大岩、壊れたレールを飛ぶトロッコ、追ってくる番人)と **宝倉庫**: 10階建ての足場、はしご、
   すき間、ロープ、金の延べ棒、槍を持つ番人、最上階の黄金の仮面。ジャンプに失敗すると川に落ち、**水路**が **噴水** と **空落ち**、
   そして **ピラミッド** へ運びます。ピラミッドでは3つの大岩が階段を転がり、そのたびにかがんでやり過ごします。そのあとは、また森です。
7. **キャンプ**: 音楽がない状態が1分を超えると、コードが降る夜の焚き火のそばで、魚を食べて眠ります。音が戻ると、同じ場面の続きから、
   1日進んで再開します。

静かな曲では世界が暗くなって何も来ません(緊張感)。大きな音では明るくなって、より多く来ます。
遊んでいる間、画面に文字は出ません(KeySpeaker と同じです)。ただし、宝倉庫の短い題字 2つ(入ったときの「THE TREASURY」と、仮面を取ったときの
「GOLDEN MASK」)だけは出ます。`d` キーで、1秒あたりのコマ数、解析と描画の時間、拍の数、ステージ名、日数、テンポが出ます(実機での確認用)。
`d` を出している間は、`n` と `p` で次と前のステージに飛べます。

## 現在の状態

WEB 版のステージは、すべて移植しました。1つ加えるたびに、Cardputer ADV 1台で、USB 音声を流して動かしました。1秒に28〜30コマ、
1コマの描画は4〜16 ms(いちばん重いのは宝倉庫)、空きヒープは約 87 KB でした。開発中のことで、知っておいてほしい点が2つあります。

- 初期のビルドが、起動時に落ちました。ゲームの関数は 8 KB のループタスクのスタックで動き、その中の1つが大きな状態をスタックに作っていたためです。
  直してあり、`firmware/build.sh` は、ゲームの関数が 2.5 KB を超えるスタックを使うビルドを、通さなくなりました。
- 初期の宝倉庫のビルドで、音楽は鳴っているのに画面が固まったことが、1度ありました。そのあと約20分見ていても再び起きず、
  コンピューター上でも再現できませんでした。原因は不明です。それ以来、ループのウォッチドッグを有効にし、ループがどこで止まったかを
  シリアルログに残しています。ウォッチドッグが働いたときに本体がどうなるかは、試していません。

マイク入力、BLE、Pico 2 の AUX ユニット、MP3 の再生は KeySpeaker のものです。ゲームを入れた状態では、確かめ直していません。

`firmware/BeatAdventure_S0/beatadv.h` は、WEB 版の拍の追跡(`beat.js`)と音の解析を C++ に移したものです。コンピューター上では、WEB 版のテストと
同じ結果になります。ゲーム本体は `ba_game.h`(ステージ)、`ba_hero.h`(探検家。太い線で描いた骨格)、`ba_gfx.h`(描画層)で、Arduino のヘッダーを使わない
普通の C++ です。

## キー

キーは KeySpeaker のものです(全部は、KeySpeaker の README を見てください)。よく使うものは、Space で再生と一時停止、`,` と `/` で前後の曲
(MP3 ではジャンプ)、`[` と `]` で音量、`\` でミュート、`Fn` + `I` で入力の切り替え(USB、マイク、AUX、MP3)、`Fn` + `M` で画面の切り替え、
`h` でヘルプです。このゲームだけのキーは、`d` で数字の表示、表示中に `n` と `p` で次と前のステージに飛ぶことです。

## ビルド

```bash
firmware/build.sh BeatAdventure_S0
```

`arduino-cli`、`m5stack:esp32` コア 3.3.10、ライブラリ M5Cardputer、M5Unified、M5GFX が必要です。設定とリンカーのオプションは KeySpeaker と同じです
(`firmware/build.sh` を見てください)。アプリだけの `BeatAdventure_S0.ino.bin` は約 1.2 MB です。ランチャー経由で入れてください。
Arduino IDE の **Upload** は、ブートローダーとパーティションテーブルも書き換えるので、使わないでください。

注意: 試した1台では、M5Launcher の Web からのアップロードが「Update Fail: 3」で失敗しました。原因はたぶん(確かめてはいません)、アプリの枠が
約 1.18 MB で、イメージより小さかったことです。同じことが起きたら、ランチャーのアプリの枠の大きさを確かめてください。

## テスト(コンピューターだけで動きます)

```bash
host/run_tests.sh
```

WEB 版の `test/beat.test.js` と同じ合成信号での拍の追跡、音の解析、ステージごとのゲームのルール(宝倉庫、水路、ピラミッド、キャンプなど)、
そして、ランダムな音楽、静かな時間、長い無音を混ぜた1時間分の通しを、アドレスと未定義動作の検査つきで動かします。C++ のコンパイラーだけで動きます。
`host/preview.cpp` は、コンピューター上でゲームの絵を描きます(WEB 版との見比べ用)。
