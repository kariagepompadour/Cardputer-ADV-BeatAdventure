# BeatAdventure

**宇宙大戦の次の舞台は、古代遺跡だ！ ビートが、俺の魂を奮い立たせる。**

BeatAdventure は、M5Stack Cardputer ADV(画面 240 x 135)用の、音楽で動く冒険ゲームです。好きな音楽を流すと、探検家がジャングル、宝倉庫、
古代のピラミッドを、拍に合わせて走り、登り、泳ぎ、落ちていきます。大きな音では世界が明るくなって危険が増え、静かな音では暗くなって、
すべてが息をひそめます。**遊ぶのではなく、眺めて、聴くゲームです。**

## 眺めるだけのゲーム

お金がなくても、いるだけでワクワクした、ゲームセンター。

そこに、新しいゲームが入った。むちゃくちゃ面白そうだ。けれど、ポケットの100円は大事で、簡単には使えない。
だから、興奮して握りしめた100円を汗まみれにしながら、遊んでいる子の後ろから、画面をのぞいていた。それだけで、満足だった。
心の中では、口出しもしていた。「俺なら、そこはそうしないのに」「そこじゃない、もっと右！」

BeatAdventure は、あのときの気持ちのためのゲームです。ボタンも、100円も、いりません。探検家は、あなたの音楽に合わせて、自分で冒険に出ます。
彼が穴に落ちても、岩にかがんでも、あなたは、あの頃のまま、後ろから眺めて、好きに口出ししていればいいのです。

[KeySpeaker](https://github.com/kariagepompadour/Cardputer-ADV-KeySpeaker) の姉妹品です。同じファームウェア(USB スピーカー、USB と BLE
のキーボード、エアマウス、ジョグダイヤル、内蔵マイク、Pico 2 の AUX ユニット、microSD の MP3)の画面が、このゲームになっています。

**まずはブラウザで遊べます: https://kariagepompadour.github.io/BeatAdventure-WEB-DEMO/**
この実機版は、この WEB 版を元に移植しました。見た目と動きの基準は、WEB 版です。

## どんな場面が出るか

長い旅が、ぐるっとつながって繰り返されます。どの場所も、音楽に反応します。

1. **客船**: 船のはしごを、拍ごとに1段ずつ登り、タラップを下ります。
2. **浜辺**: 去っていく船、ヤシの木からココナッツを投げるサル、跳び越えるウミガメと流木、仮面の狩人、曲が静かになると隠れる茂み。
3. **森と崖**: トラ、クマ、リンゴ。そして、落石とコンドルのなか、地すべりの壁を登ります。
4. **ツルの谷、ボートと滝**: 3本のツルで谷を渡り、ボートで滝を落ちます。
5. **川と平らな森**: ワニ、ピラニア、水ヘビ。ツルで渡る池。台座の上の黄金の仮面と、隠し穴。
6. **トンネルと宝倉庫**: 矢のわな、転がる大岩、トロッコ、追ってくる番人。そして、10階建てのはしご、すき間、ロープ、金の延べ棒と、最上階の
   黄金の仮面。ジャンプに失敗すると川に落ち、川が水の噴き出しで彼を押し上げ、**ピラミッド**へ落とします。ピラミッドでは3つの大岩が階段を
   転がり、そのたびにかがんでやり過ごします。そのあとは、また森です。
7. **キャンプ**: 音楽がない状態が1分を超えると、コードが降る夜の焚き火のそばで、魚を食べて眠ります。音が戻ると、同じ場面の続きから、
   1日進んで再開します。

遊んでいる間、画面に文字は出ません。ただし、宝倉庫の短い題字 2つ(入ったときの「THE TREASURY」と、仮面を取ったときの「GOLDEN MASK」)だけは出ます。

## 必要なもの

- M5Stack **Cardputer ADV**。
- 音楽。Cardputer を、パソコンやスマートフォンに USB でつなぐと、USB スピーカーとして見えます。そこへ音楽を流すと、ゲームがその音を聴きます。
  (内蔵マイクも、KeySpeaker と同じように使えます。ゲームを入れた状態では、確かめ直していません。)

## 入れ方

出来合いのイメージはまだありません。自分でビルドして、ランチャー経由でアプリを入れてください。

```bash
firmware/build.sh BeatAdventure_S0
```

`arduino-cli`、`m5stack:esp32` コア 3.3.10、ライブラリ M5Cardputer、M5Unified、M5GFX が必要です(設定は KeySpeaker と同じです。`firmware/build.sh` を
見てください)。アプリだけの `BeatAdventure_S0.ino.bin`(約 1.2 MB)ができるので、それをランチャー経由で入れます。
Arduino IDE の **Upload** は、ブートローダーとパーティションテーブルも書き換えるので、使わないでください。

ランチャーの Web からのアップロードが失敗するときは(試した1台では、「Update Fail: 3」で失敗しました)、ランチャーのアプリの枠の大きさを確かめて
ください。その1台では、枠が約 1.18 MB で、イメージより小さかったことが、たぶん原因でした(確かめてはいません)。

## 使い方

- `Space` で再生と一時停止、`,` と `/` で前後の曲(MP3 ではジャンプ)、`[` と `]` で音量、`\` でミュート、`Fn` + `I` で入力の切り替え
  (USB、マイク、AUX、MP3)、`Fn` + `M` で画面の切り替え、`h` でヘルプです。これらは KeySpeaker のキーです。全部は、KeySpeaker の README を見てください。
- `d` で、ゲーム画面に小さな数字が出ます。1秒あたりのコマ数、解析と描画の時間、拍の数、ステージ名、日数、テンポです。出している間は、
  `n` と `p` で次と前のステージに飛べるので、待たずに、見たい場面を見られます。

## 知っておいてほしいこと

WEB 版のステージは、すべて移植しました。1つ加えるたびに、Cardputer ADV 1台で、USB 音声を流して動かしました。1秒に28〜30コマ、1コマの描画は
4〜16 ms(いちばん重いのは宝倉庫)、空きヒープは約 87 KB でした。開発中のことで、2点あります。

- 初期のビルドが、起動時に落ちました。ゲームは 8 KB のループタスクのスタックで動き、その中の1つの関数が、大きな状態をスタックに作っていたためです。
  直してあり、`firmware/build.sh` は、ゲームの関数が 2.5 KB を超えるスタックを使うビルドを、通さなくなりました。
- 初期の宝倉庫のビルドで、音楽は鳴っているのに画面が固まったことが、1度ありました。そのあと約20分見ていても再び起きず、コンピューター上でも
  再現できませんでした。原因は不明です。それ以来、ループのウォッチドッグを有効にし、ループがどこで止まったかをシリアルログに残しています。
  ウォッチドッグが働いたときに本体がどうなるかは、試していません。

マイク入力、BLE、Pico 2 の AUX ユニット、MP3 の再生は KeySpeaker のものです。ゲームを入れた状態では、確かめ直していません。

## 開発者向け

- `firmware/BeatAdventure_S0/beatadv.h`: WEB 版の拍の追跡(`beat.js`)と音の解析を C++ に移したものです。コンピューター上では、WEB 版のテストと
  同じ結果になります。
- `ba_game.h`(ステージ)、`ba_hero.h`(探検家。太い線で描いた骨格)、`ba_gfx.h`(描画層): Arduino のヘッダーを使わない普通の C++ なので、同じコードが
  コンピューター上でも動きます。`host/preview.cpp` は、そこでゲームの絵を描きます(WEB 版との見比べ用)。
- テスト(コンピューターだけで動きます。C++ のコンパイラーだけで足ります):

  ```bash
  host/run_tests.sh
  ```

  WEB 版の `test/beat.test.js` と同じ合成信号での拍の追跡、音の解析、ステージごとのゲームのルール(宝倉庫、水路、ピラミッド、キャンプなど)、
  そして、ランダムな音楽、静かな時間、長い無音を混ぜた1時間分の通しを、アドレスと未定義動作の検査つきで動かします。
